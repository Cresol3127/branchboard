Complete feature summary

1. Infinite canvas: Pan, zoom, drag, multi-select, grid snapping, minimap, auto-layout, and intelligent collision avoidance.

2. Node system: Create, connect, resize, duplicate, group, collapse, and organize different node types.

3. Conversation branching: Multiple child nodes from a common parent, shared parents, multi-parent merging, and independent conversation branches.

4. AI conversations: Streaming responses, regeneration, editing, retries, parallel generation, and conversation history.

5. Multi-model AI: Switch models between nodes using OpenAI, Anthropic, Gemini, OpenRouter, Groq, Ollama, and other providers.

6. Context management: Automatically inherit context, manually include/exclude nodes, combine branches, and inspect exactly what reaches the AI.

7. Token intelligence: Per-node, branch, selected-node, and board token counts, context limits, cost estimates, and usage tracking.

8. Multimodal support: Upload and preview images, videos, PDFs, audio, code, and documents, with extraction and AI processing where supported.

9. Sticky notes and annotations: Rich-text notes, freehand drawing, shapes, arrows, highlighting, checklists, and annotation layers.

10. Color-coded families: Automatically assign and inherit colors across conversation trees, with manual overrides, visible on automatic connections.

11. Keyboard shortcuts: Shortcuts for node creation, navigation, editing, model switching, canvas operations, and a command palette.

12. Node resizing: Automatic content-based sizing, manual resizing, and collision-aware repositioning.

13. Workspace management: Multiple projects, boards, folders, templates, favorites, search, autosave, and version history, with independent dockable, floating, snapped and maximized workspace windows.

14. Import/export: JSON backups, Markdown, images, PDFs, full workspace backups, and conversation imports.

15. Collaboration: Shared workspaces, permissions, live cursors, real-time editing, comments, and shareable boards.

16. Advanced AI tools: Multi-model comparisons, prompt libraries, reusable context, AI summaries, semantic search, RAG, and workflow automation.

17. Analytics: Token usage, estimated and actual API costs, provider statistics, spending budgets, and generation history.

18. Customization: Light/dark themes, canvas settings, node appearance, colors, shortcuts, model defaults, and provider settings.

19. Security: Authentication, encrypted API keys, access controls, secure uploads, rate limiting, and data protection.

20. Performance: Optimized rendering, lazy loading, efficient graph traversal, and support for thousands of nodes.

21. Data reliability: Persistent storage, undo/redo, autosave, recovery, snapshots, and protection against data loss.

22. Production deployment: Database, migrations, environment configuration, automated tests, CI, documentation, and deployment setup.

23. Onboarding: Guided setup, example boards, templates, tooltips, and a demo mode without requiring API keys.

24. Testing: Functional, integration, end-to-end, security, accessibility, and performance testing.
